# IMF Canada 2024 – AI Financial Analysis

This project analyses Canada's 2024 IMF Article IV report using Python and Google Colab.

The notebook covers four tasks:
1. Extract and summarise the PDF using Gemini.
2. Identify financial risks and extract key economic figures.
3. Answer questions using RAG and FAISS.
4. Create charts showing the results.

## How to run

1. Open `IMF.ipynb` in Google Colab.
2. Upload the IMF Canada 2024 report PDF when prompted.
3. Add your Gemini API key in Colab **Secrets** as `Gemini_API_Key`.
4. Run the notebook cells in order, starting from the setup section.

The notebook generates summaries, extracted data, evaluation results and dashboard charts.
